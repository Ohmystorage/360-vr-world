컨트롤러 안내판 시안: 헤드셋 안에서 보이는 안내 카드

실제 월드 화면 위에 바뀔 모습을 그려 넣은 시안 (글은 영어) · 프로젝트 파일은 아직 바꾸지 않음

② 다시 보고 싶을 때

오른쪽 위 Exit VR 옆에 작은 버튼 ? Controls가 항상 있음. 선으로 가리키고 트리거를 당기면 안내판이 다시 열림 (그림 오른쪽 위).

들어가는 내용 (Quest에 이미 만들어진 것 그대로)

  • 1 왼쪽 스틱 = 걷기
  • 2 오른쪽 스틱 좌우 = 30° 돌기
  • 3 오른쪽 스틱 위아래 = 카드 가깝게/멀게
  • 4 선 + 트리거 = 분홍 고리·Close·Exit VR 누르기
  • 5 A 또는 X = 카드 열기/닫기
  • 고개 = 둘러보기
컨트롤러 그림은 코드로 그린 단순한 모양 (실제 모양과 똑같지는 않음).

바뀌는 파일

js/vr.js 만 고침 (카드 만드는 방식을 그대로 가져다 씀) + world.html의 ?v= 번호 올림. 컴퓨터 화면, 키보드 속도, 카드 글은 그대로.
별도 웹페이지는 만들지 않음 (헤드셋 안에서 보는 것이 목적).
정할 것 — 처음 들어갈 때 자동으로 뜨게 할지, ? Controls 버튼만 두고 학생이 직접 열게 할지. 시안은 자동 + 버튼 둘 다.
