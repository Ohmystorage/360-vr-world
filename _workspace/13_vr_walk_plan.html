2단계 시안 (수정 2): 조이스틱 = 키보드 ↑↓←→ · 둘러보기는 고개로 · 카드는 A/X (Quest 2 / 3 / 3S)

실제 세계 화면 위에 움직임을 그려 넣은 시안 · 프로젝트 파일은 아직 바꾸지 않음

컨트롤러 버튼 (전부 이것뿐)

왼쪽 또는 오른쪽 조이스틱걷기: 키보드 ↑↓←→와 똑같이
A/X한 번 = 카드 열기 (분홍 안내판이 보일 때)
또 한 번 = 카드 닫기
헤드셋 (고개·몸)둘러보기: 위·아래·좌우·뒤
B/Y · 방아쇠 · 그립쓰지 않음 (레이저도 없앰)
1단계에서 함께 고칠 것
· 분홍 안내판: Read the message · press A or X
· 카드 아래: Close 버튼 대신 Press A or X again to close
· 레이저·방아쇠로 고리 열기, B/Y 닫기 → 없앰
이 표가 나중에 학생용 컨트롤러 안내 페이지(영어)의 내용이 됨

바뀌는 것 / 그대로인 것

헤드셋 안에서만
· 두 조이스틱 모두 키보드 ↑↓←→처럼 걷기, 걷는 동안 가장자리 어둡게
· 키보드와 같은 벽: 마당 밖이나 물건(쿠키, 신발, 화분…) 속으로 못 들어감. 카드가 열려 있으면 못 걸음
· 헤드셋을 쓰면 컴퓨터에서 보던 방향 그대로 시작 (지금은 무조건 북쪽을 보게 됨)
그대로: 컴퓨터 화면, 키보드 걷기 속도(acceleration 357.5), 장소 위치, 카드 글
확인 방법: 컴퓨터에서 조이스틱 입력을 흉내 내 속도·벽을 키보드와 비교 → 1·2단계를 함께 GitHub에 올려 선생님이 Quest에서 한 번 확인
써 보고 정할 것: 헤드셋 속 속도 — 키보드와 같은 속도(약 65 m/s)도 헤드셋에서는 훨씬 빠르게 느껴질 수 있음. 어지러우면 헤드셋에서만 낮추기(숫자 하나만 바꾸면 됨)
